# FlowFit - MVP Ideas

### Core Problem

Lack of enjoyment from working out due to mismatched, boring, and repetitive training plans. Available tools are overly complicated and poorly suited to the individual user, and the workouts themselves are dull.

### Minimum Feature Set

- **Authentication:** Simple user registration and login system.
- **Exercise Library:** A ready-made list of exercises imported by the developer (outside the agent flow), categorized by difficulty level and muscle group.
- **Onboarding Survey:** A few questions at the start (goal, experience level, available equipment, preferred style), used to build a user profile.
- **AI Agent (V1):** Based on the survey, matches and suggests an optimal set of exercises for the user to get started.
- **Workout Screen:** Ability to launch a plan and log completed reps, sets, and weights in real time.
- **History (Instead of a Calendar):** A simple, chronological list of completed workouts with a view of recorded results.

### What Is NOT in Scope for MVP

- **Advanced AI (V2):** Progress analysis over time, automatic exercise swaps, and dynamic weight progression suggestions.
- **Full Calendar View:** A visual grid of days and months.
- **Analytics & Charts:** Training volume charts, strength statistics.
- **Social Module:** Sharing workouts, competing with friends.
- **Monetization:** Ads, payments, subscriptions (the app is intended to be free/private).

### Success Criteria

- **Technical:** The app runs stably at the MVP level; the database correctly stores exercise data.
- **User-facing:** A user is able to log in, complete the survey, receive a personalized workout, perform it, log sets/weights, and finally see that workout on the history list.
